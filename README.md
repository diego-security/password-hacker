# 🔐 PASSWORD HACKER

### Password Security Analyzer & Generator
### Analizador y Generador de Contraseñas

A free Python tool to analyze password strength and generate cryptographically secure passwords.

Una herramienta gratuita desarrollada en Python para analizar la seguridad de contraseñas y generar contraseñas criptográficamente seguras.

## 🚀 FEATURES / FUNCIONES

- Password strength analysis / Análisis de seguridad.
- Cryptographically secure generation / Generación criptográfica.
- Three password lengths / Tres longitudes disponibles.
- Security recommendations / Recomendaciones de seguridad.
- Estimated password cracking time / Tiempo estimado de descifrado.
- Spanish and English support / Soporte en español e inglés.

## 🛠️ REQUIREMENTS / REQUISITOS

- Python 3.10 or newer.
- Python package: zxcvbn.

## 📥 INSTALLATION / INSTALACIÓN

Clone the repository / Cloná el repositorio:

    git clone REPLACE_WITH_REPOSITORY_URL

Enter the project directory / Entrá en la carpeta:

    cd password_hacker

Create a virtual environment / Creá un entorno virtual:

    python3 -m venv .venv

Activate it on Linux / Activarlo en Linux:

    source .venv/bin/activate

Install dependencies / Instalá las dependencias:

    python -m pip install -r requirements.txt

## ▶️ HOW TO USE / CÓMO UTILIZAR

Run the application / Ejecutá la aplicación:

    python main.py

Choose between / Elegí entre:

1. Analyze a password / Analizar una contraseña.
2. Generate a password / Generar una contraseña.
3. Exit / Salir.

## 🔒 SECURITY / SEGURIDAD

- Password generation uses Python's secrets module.
- Password analysis is performed locally.
- Passwords are not stored or transmitted by the application.
- Cracking times are estimates, not guarantees.

- La generación utiliza el módulo secrets de Python.
- El análisis se realiza localmente.
- La aplicación no guarda ni transmite las contraseñas.
- Los tiempos de descifrado son estimaciones, no garantías.

Esta herramienta tiene fines educativos y no garantiza seguridad absoluta.
